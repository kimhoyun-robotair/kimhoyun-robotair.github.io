## Overview

**DARAM-G** is an undergraduate rover project developed to bring together robotic software, a custom hardware platform, and simulation-based testing.

The first rover, **DARAM-G Mk.I**, combined an RGB-D camera and 2D LiDAR for autonomous exploration. The work included a Gazebo simulation environment, rover hardware development, and testing in real environments.

## Award

DARAM-G received the **Hanwha Aerospace CEO Award** at the **2025 National University Capstone Design Competition**, hosted by **The Society for Aerospace System Engineering (SASE)**.

The [official competition page](https://sase.or.kr/Conference/ConferenceView.asp?AC=2&B_CATE=BBC2&CODE=CI20250101) provides the event and award information. The [project repository](https://github.com/kimhoyun-robotair/DARAM-G) records the Mk.I development and award.

## Code

The repository’s main branch introduces the broader DARAM-G project, while the `v1` branch contains the first rover’s development. See the [DARAM-G repository](https://github.com/kimhoyun-robotair/DARAM-G) for the project history and software.
